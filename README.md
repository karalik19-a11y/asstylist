# Asstylist — ИИ-стилист

Веб-приложение, которое ведёт ваш гардероб и собирает образы под повод, сезон, погоду,
цветотип и историю носки. Всё считается локально в браузере: без сервера, без API-ключей,
без передачи данных куда-либо.

## Что внутри

**Гардероб** — карточки вещей с фото, цветом, категорией, стилями, сезонами, теплом и
формальностью; поиск и фильтры, избранное, загрузка фото (сжимается до 640 px и хранится
локально).

**Студия образов** — выберите повод (работа, прогулка, свидание, вечеринка, спорт, поездка,
дом), сезон и температуру: стилист предложит до 6 комплектов, каждый с оценкой 0–100 и
расшифровкой. Любую вещь в образе можно заменить кнопкой «⇄» — оценка пересчитается на месте.

**План на неделю** — семь образов подряд; надетые вещи учитываются в следующие дни, поэтому
гардероб равномерно прокручивается и комплекты не повторяются.

**Профиль** — цветотип («Зима/Лето/Весна/Осень» и его палитра), любимые стили, цвета, которых
вы избегаете, сохранённые образы, экспорт/импорт JSON и очистка данных.

## Как считается оценка

Образ оценивается по шести критериям (суммарно 100 баллов), и каждый критерий виден в карточке:

| Критерий             | Вес | Что учитывает                                                            |
| -------------------- | --- | ------------------------------------------------------------------------ |
| Гармония цвета       | 26  | цветовой круг: комплементарные пары, триада, родственные оттенки, монохром; штраф за «пестроту» |
| Соответствие случаю  | 22  | формальность комплекта против целевой для повода (1–5)                    |
| Стиль и целостность  | 16  | доля вещей в ожидаемых стилях и наличие одного объединяющего стиля        |
| Цветотип             | 12  | близость цветов к палитре сезона, штраф за цвета из списка «не носить»    |
| Погода и сезон       | 14  | тепло комплекта против нужного при заданной температуре; верхний слой ниже +8 °C |
| Свежесть ротации     | 10  | давно ли вещь выходила в свет                                            |

Движок перебирает схемы комплекта (платье либо верх+низ, плюс обувь, верхняя одежда, сумка,
аксессуар), отбирает лучшие кандидатуры в каждый слот, оценивает сочетания и дополнительно
штрафует похожие комплекты, чтобы выдача была разнообразной. Плюс отдельный аудит гардероба:
чего не хватает по категориям, сезонам, формальности и нейтральной базе.

## Стек и запуск

React 18 + TypeScript + Vite 6, состояние и хранилище — React Context + localStorage.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc --noEmit + сборка в dist/
npm run preview    # предпросмотр сборки
npm run typecheck
```

## Структура

```
src/
  types.ts                  модель данных (вещь, образ, профиль, разбор оценки)
  lib/
    color.ts                HSL, цветовые схемы, палитры цветотипов
    catalog.ts              категории, стили, сезоны, поводы и схемы комплектов, демо-вещи
    stylist.ts              оценка образа, генератор образов, план недели, аудит гардероба
    storage.ts              чтение/запись localStorage, импорт-экспорт, нормализация
    image.ts                сжатие загруженного фото
  state/AppState.tsx        контекст приложения: гардероб, профиль, образы, история носки
  components/               экраны (Гардероб, Студия, Неделя, Профиль) и карточки
public/items/               снимки вещей демо-гардероба
```

## Данные

Всё хранится в `localStorage` под ключом `asstylist:v1`. Кнопка «Скачать JSON» в профиле
делает резервную копию, «Импортировать JSON» — восстанавливает её. Первый запуск пустой:
можно нажать «Загрузить демо-гардероб» (13 базовых вещей) или добавить свои.
